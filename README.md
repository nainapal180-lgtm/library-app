# BookVerse Library App

An online library application built using React and Vite.

## Features

- Home page with book categories
- Popular books displayed in cards
- Browse books by category
- Search books by title or author
- View detailed information about each book
- Add a new book using a form
- Form validation
- Redux for managing the books state
- Dynamic routing using React Router
- 404 Page Not Found for invalid routes

## Technologies Used

- React
- Vite
- React Router DOM
- Redux Toolkit
- CSS
